# Sample annotations

Поместите сюда маленький конвертированный YOLO-format пример из DOTA с сохранённой ссылкой на источник и лицензию. Не смешивайте test images с train/val. Синтетические изображения из `scripts/prepare_data.py` не имеют ground truth объектов и используются только для проверки pipeline.
