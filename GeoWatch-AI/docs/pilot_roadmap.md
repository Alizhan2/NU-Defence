# Pilot roadmap

1. Согласовать классы, качество входа, acceptance metrics и режим доступа.
2. Подготовить лицензированный scene-level split и baseline YOLOv8n/v8s.
3. Сравнить модели, thresholds и tile sizes; провести robustness tests.
4. Ввести роли, audit trail, защищённое хранилище и асинхронные jobs.
5. Провести пилот с экспертами и измерить correction rate/time saved.
6. После проверки ядра — georegistered режим «До/После» только как кандидаты `needs_review`.
