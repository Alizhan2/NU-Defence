# Тестовые снимки GeoWatch

Эта папка предназначена для ручной проверки продукта, а не для обучения или
оценки модели. Реальные файлы в `real_pair/` не добавляются в Git.

## Пара «до / после»

Источник: публичный [Maxar ARD sample-002](https://ard.maxar.com/docs/getting-started/getting-started/).
Выбрана одна и та же сцена `031133231113`:

| Файл | Дата | Назначение |
|---|---:|---|
| `real_pair/cropped/before_crop_2020-11-18.tif` | 18.11.2020 | Готовый 4096×4096 GeoTIFF для загрузки в GeoWatch |
| `real_pair/cropped/after_crop_2021-01-16.tif` | 16.01.2021 | Готовый 4096×4096 GeoTIFF для загрузки в GeoWatch |

Это открытые демонстрационные Analysis Ready Data от Maxar. Перед внешней
публикацией или коммерческим использованием проверьте актуальные условия
источника. Для конкурса сохраняйте исходный URL, даты и метаданные снимка.

## Сценарий проверки

1. Откройте «Изменения» в GeoWatch.
2. Загрузите два файла из `real_pair/cropped/` в соответствующие поля.
3. Проверьте качество, CRS, overlap и отчёт о совмещении.
4. Запустите сравнение и оставьте все найденные изменения в статусе
   `needs_review`, пока аналитик не подтвердит их вручную.

## Другие источники

- [OpenAerialMap](https://imagery.hotosm.org/) — поиск открытых аэроснимков
  по области, дате и поставщику; выбирайте исходные данные с явной лицензией.
- [Copernicus Browser](https://browser.dataspace.copernicus.eu/) — Sentinel-2
  для повторяемых среднеразрешённых сцен.
